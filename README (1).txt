NEXA GAMES STÜDYO — İLK VE SON / BÖLÜM 1 MOBİL DEMO

MOBİLDE OYNAMA
1. ZIP dosyasını çıkar.
2. index.html dosyasını Android telefonda Chrome ile aç.
3. İlk açılışta internet bağlantısı gerekir (Three.js kütüphanesi CDN'den yüklenir).
4. Sol joystick ile hareket et.
5. Ekranın sağ tarafında parmağını sürükleyerek kamerayı çevir.
6. ETKİLEŞ butonuyla kasetleri, kayıtları ve paneli kullan.

BİLGİSAYARDA
WASD ile hareket, fare ile kamera, E ile etkileşim. ESC fareyi serbest bırakır.

PAYLAŞIM
WhatsApp'tan ZIP dosyası olarak gönderebilirsin. Arkadaşın ZIP'i çıkarmalı ve index.html dosyasını tarayıcıda açmalı.
Daha kolay ve güvenilir paylaşım için klasör içeriğini GitHub Pages'e yükleyip site bağlantısını gönderebilirsin.

NOT
Bu bir ilk prototiptir; tam oyun değildir. Tarayıcıda açmak için internet gerekir. Bazı telefonlarda yerel HTML dosyası açma kısıtları olabilir; GitHub Pages bağlantısı daha güvenilir seçenektir.
